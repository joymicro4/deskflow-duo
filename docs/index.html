01 / A SIMPLE IDEA

共享的是键鼠。
保留的是习惯。

Deskflow 负责跨屏传输，Duo 负责识别你正在使用的物理设备。合成输入不会触发抢控；内建触控板通过 Multitouch 单独检测。切回 MacBook，先划一下触控板请求接管；键盘默认不触发切换。

01

识别物理输入

IOHIDManager 监听内建或外接设备，可按产品名称过滤。持续移动或触摸达到阈值才触发；键盘默认不抢主控。

02

改变控制方向

两端服务就绪，监督进程协调客户端连接。TLS 加密，双方校验指纹；同一时间收敛到一个主控方向。

03

留一条手动退路

命令一键接管。doctor 定位授权、设备独占和配置问题；停止或卸载时保留可恢复备份。

03 / MAKE IT YOURS

一套可复现的
桌面配方。

两台 Mac，同一可信网络。先安装 Deskflow、Python 3 和 Xcode 命令行工具，再用配置文件描述你的桌面。

阅读完整安装与排障指南 ↗
● ● ● Terminal / 每台 Mac 分别执行
git clone https://github.com/joymicro4/deskflow-duo
cd deskflow-duo
cp config/example.json config/local.json
# 编辑设备名称、地址、布局与输入规则
./scripts/install.sh config/local.json mac-left
python3 scripts/duo.py fingerprint
# 核对并互相信任对方证书指纹
python3 scripts/duo.py trust PEER_SHA256
python3 scripts/duo.py permissions
python3 scripts/duo.py start
python3 scripts/duo.py doctor
敲另一台 Mac 的键盘，文字会去哪里？

被控端的本地键盘始终输入本机；主控端的键盘才会跟随跨屏光标转发。请先移动你要使用的那套指针，再开始打字。键盘默认不会抢控。

先把边界说清楚。

我需要这套方案，还是通用控制？

只有 Apple 设备、Apple 账户条件也适合时，先尝试 macOS 通用控制。Duo 面向希望明确控制设备来源、TLS 信任与切换策略的双 Mac 桌面。

支持三台以上，或任意屏幕排列吗？

v0.1 自动仲裁只支持两台 Mac，左右顺序可配置。多机拓扑会被校验器拒绝。Mac 内部的多显示器边缘需要在系统设置中对齐。

为什么授权后还是没有反应？

给 Duo Auto Switch 开启输入监控，给 Deskflow 开启辅助功能，然后重启。Karabiner 可能独占键盘；用 doctor 和日志定位，不要直接卸载已有工具。

内建触控板在所有 macOS 上都能用吗？

它依赖 macOS 私有 MultitouchSupport 框架，系统更新可能改变行为。物理触摸读取已验证，触摸触发接管的完整链路仍待真机验收。不兼容时仍可使用外接鼠标或手动接管。本地编译版本未做 Apple 公证。
