01 / YOUR DESK, YOUR WAY

不用改掉习惯，
也不用换掉账号。

坐在桌前用外接键鼠，拿起 MacBook 就用内建触控板。物理指针决定主控方向，键盘跟随光标，不会因为敲另一副键盘突然抢控。适合你自己的两台 Mac，也能在设备权限和组织策略允许时，配置不同账号的同事或公司 Mac。

01

指针决定主控

外接鼠标通过 IOHID，内建触控板通过 Multitouch 检测物理活动；三秒防抖，键盘默认不抢控。

02

键盘跟随光标

被控端物理按键经 ChaChaPoly 通道返回主控端，再按光标位置路由。双方配对，断线自动放行本机输入。

03

开源，也有退路

源码、安装脚本、doctor 和 AI Skill 都在仓库里。⌃⌥⌘K 关闭键盘转发；手动接管 App 随时兜底。

02 / SAME DESK. DIFFERENT NEEDS.

和通用控制，差在哪？

你关心的事 Deskflow Duo macOS 通用控制
同一个 Apple ID 不需要，网络与密钥配对 需要相同 Apple Account + 双重认证
同事 / 公司 Mac 可以不同账号；需设备授权与组织策略允许 不同账号不满足其账户要求
键盘跟随光标 两副键盘均可，启用 v0.2 转发 支持连接设备间的键鼠操作
开源与配置 Duo MIT，Deskflow GPL-2.0；规则可查可改 Apple 系统内建，未作为开源项目提供
设备范围 当前两台 Mac，需安装及授权 支持的 Mac / iPad，需满足系统与连接条件

通用控制要求依据 Apple 官方说明 ↗。两者均不是显示器信号切换器。

先把边界说清楚。

键盘跟随光标，四种组合都测过了吗？

用户已在原始双机环境确认两种主控 × 两个光标位置全部可用。通用安装包另有协议加固与恢复逻辑，需要在你的机器上验收。安全输入（密码框）可能无法拦截，按键留在本机；输入法和布局以主控端为准。

需要登录同一个 Apple ID 吗？

不需要。Duo 通过网络、TLS 证书指纹和共享密钥配对，不获取 Apple 账户凭据。公司设备仍须遵守权限及组织策略。

断线或临时不想转发键盘怎么办？

通道不可用时放行本地输入，并清理注入的按键和修饰键。⌃⌥⌘K 可紧急切换，状态会保留；也可使用手动接管 App。突断时少量已排队按键可能丢失。

支持多机、所有系统和任意布局吗？

当前只支持两台 Mac 的左右布局。内建触控板依赖私有 MultitouchSupport，系统升级可能改变行为，静止接触也可能触发。唤醒时重建监听，但仍需逐机复测。本地 ad-hoc 构建未做 Apple 公证；签名仅认 bundle id 的权衡详见 README。
